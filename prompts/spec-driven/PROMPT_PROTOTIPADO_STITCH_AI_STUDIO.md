# Prompt de arranque — Prototipado web

Usa la Skill `stitch-design-to-frontend`.

```text
Quiero diseñar el frontend del sistema descrito en ../PRD.md.

Trabaja primero en Stitch. La estética es libre por estudiante, pero todas las pantallas funcionales obligatorias del PRD deben estar cubiertas. No agregues backend ni Firebase durante diseño/prototipado.

Cuando el diseño esté listo, detente y solicita aprobación explícita. Solo después genera el handoff a Google AI Studio.

En Google AI Studio elegiré React o Angular desde la configuración del proyecto. El resultado se importará a este repo `citas-web` y posteriormente se integrará directamente contra la API Spring Boot.

La fuente de verdad visual será el diseño aprobado. La reconciliación posterior debe corregir solo divergencias, no rediseñar.
```
