# Dominio

HECHO: proyecto académico con pacientes y profesionales sintéticos; no representa sistemas internos reales de FCV.

Actores del PRD: USER (paciente), PROFESSIONAL (agenda propia), ADMIN (catálogos y autorizaciones). S2 implementa solo creación de cuentas USER y autenticación. Los otros roles quedan en catálogo sin cuentas precreadas.

Reglas posteriores: citas generales automáticas, especializadas aprobadas por ADMIN, slots de 30 minutos, consultas de 30/60 minutos y reprogramación con retención de ambas franjas hasta decisión. No se implementan en S2.

Fuera de alcance: historia clínica, pagos, facturación, diagnósticos y sistemas clínicos reales.

PREGUNTA ABIERTA: aprobación de HU-001, HU-002 y HU-003 y del diseño visual. No considerar estas aprobaciones como existentes hasta recibir respuesta.
